# AI Amigos governed-pilot checklist v0.1.1

This checklist is an author-controlled planning artifact. Completing it does not prove adoption, outcome, impact, endorsement, or independent review.

## Before the pilot

- Select one published pilot package and record its exact version.
- Name the participant-side decision owner and confirm a U.S. connection.
- Define one bounded job, affected people, data boundary, baseline, metric, unit, sample, success criterion, stop criterion, and follow-up date.
- Confirm that prohibited, confidential, regulated, student, employer, customer, credential, and security data will not be shared with AI Amigos.
- Obtain organizational, institutional, legal, ethics, consent, or worker notice approvals when applicable.

## During the pilot

- Freeze comparable evaluation cases before comparing approaches.
- Record system and configuration versions, cost, latency, failures, overrides, and deviations.
- Keep a human accountable for every consequential decision.
- Stop if privacy, safety, authorization, or measurement conditions fail.

## After the pilot

- Measure the same unit over a compatible window and record confounders.
- Preserve negative, inconclusive, reversed, and stopped results.
- Choose private-only, sanitized anonymous publication, or named publication separately.
- Host participant verification on a participant-controlled domain if the participant elects to verify.
- Submit only the deliberately sanitized proof pack; never raw prompts, cases, files, logs, names, or secrets.
